🔔 Notificaciones

Agrega correos que recibirán notificaciones automáticas.

Cada responsable puede suscribirse a los avisos que quiera. Los correos se envían automáticamente cuando se crea una nueva fecha, un deseo o un módulo, y como recordatorio el día antes y el mismo día de cada evento.

ℹ️ Cómo funciona:
• Cada vez que se cree una fecha, deseo o módulo → correo a los suscritos.
• El día antes y el mismo día de cada evento → recordatorio automático.
• Para activar el envío diario: en Apps Script → menú "💜 Deseos de Bartolita" → Instalar trigger diario.
